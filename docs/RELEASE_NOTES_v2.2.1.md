# Sarcophagus Constructor v2.2.1 — runtime hotfix

## Исправление критической ошибки подсказок

- Исправлен `docs-app/library-v2.js`: ранее в нём находилась только функция `attachModuleCheckboxes`, но отсутствовал глобальный объект `MODULE_LIBRARY`.
- В `library-v2.js` восстановлена фактическая библиотека модулей из `web/library.js` (30 модулей, четыре типа проектов).
- Порядок подключения скриптов в `index-v2.html` сохранён: сначала библиотека, затем `constructor-v2.js`.
- Добавлен регрессионный тест, который исполняет v2-библиотеку и проверяет наличие 30 уникальных модулей, а также порядок подключения.
- Обновлена версия до 2.2.1.

## Проверки

- `npm test`: 8/8 PASS.
- `npm run check`: PASS.

## Примечание о предупреждениях браузера

`MaxListenersExceededWarning` и `ObjectMultiplex - orphaned data` из `contentscript.js` относятся к расширению браузера/его content script и не являются причиной ошибки `MODULE_LIBRARY`. Проверять их следует отдельно, временно отключив расширения и сравнив консоль.
